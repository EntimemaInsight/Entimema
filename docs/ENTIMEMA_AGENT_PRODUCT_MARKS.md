# Entimema Agent Product Marks

## Philosophy

Entimema Agent Product Marks are compact product identities, not interface icons or miniature analytical diagrams. Their governing equation is **high graphic density with low semantic complexity**: each mark must read first as one authoritative object, then reward inspection through deliberate analytical structure.

The initial grammar is established through three prototypes only: Credit Vintage Analysis, PD Model Monitoring, and Cost & Margin. The remaining nine marks are outside this approval gate.

## Construction system

- Native SVG frame: `0 0 32 32`.
- Production footprint: optically 28px within the permanent 44×44 field.
- Primary ink: opaque Entimema deep navy (`#18364f`).
- Structural weights: filled geometry plus a single 1.9-unit outline weight where enclosure needs to remain visible.
- Corners: rectilinear forms use a restrained 4-unit cadence; probability forms use controlled continuous curves.
- Spacing: repeated structures follow a common 4-unit rhythm, adjusted optically at boundaries.
- Geometry is closed, filled, and silhouette-led. Micro-grids, dotted guides, hairlines, labels, and low-opacity semantic details are excluded.

## Ink coverage

Marks target approximately 30–45% dark coverage by optical judgement. Coverage is not measured mechanically; it is tuned so the mark behaves as an object at production size without collapsing its negative spaces.

## Decision Event

One opaque copper/orange event (`#b94824`) may identify the exact point at which information becomes decision-relevant. It is never decorative.

- Vintage: the final cohort terminal after divergence.
- PD Monitoring: the displaced observed boundary.
- Cost & Margin: the residual value chamber after decomposition.

## Mineral color fields

The 44×44 mineral fields provide editorial rhythm rather than category coding. Porcelain coral, apricot, parchment, chartreuse, mint, cyan, powder blue, and smoky lavender may repeat or alternate independently of agent function. Geometry—not hue—carries identity.

## Prototype concepts

### Credit Vintage Analysis — Cohort Object

Three staggered, filled ribbons move through a repeated temporal cadence. The lower cohort resolves into a separated warm terminal, expressing cohorts → time → divergence → decision without resembling a chart.

### PD Model Monitoring — Probability Alignment Object

Two strong enclosed probability bodies overlap around a dense common region. A warm displaced boundary makes drift actionable without using a literal bell curve or axes.

### Cost & Margin — Value Decomposition Object

A heavy outer value vessel contains repeated reductions. The diminishing layers terminate in a protected warm residual, creating the densest of the three silhouettes while retaining immediate legibility.

## 24px ↔ 2000px test

At 24–28px, every mark must remain distinguishable by silhouette with labels hidden. At extreme enlargement, curves, corners, joins, spacing, negative space, and terminals must remain intentional. Production scale is never an excuse for imprecise geometry.

## $50K quality gate

Each mark is reviewed as though it were the sole identity asset delivered by a boutique studio for a conceptual $50,000 commission. It passes only when it demonstrates instant recognition, analytical truth, proprietary geometry, optical authority, and craftsmanship at both interface and identity scales.
