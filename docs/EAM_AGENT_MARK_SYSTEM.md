# Entimema Analytical Miniatures — EAM–01

EAM turns each agent's decision mechanism into a proprietary analytical miniature. The surrounding catalogue remains restrained; complexity is concentrated within the 58px mineral field and a 38–44px optical artwork footprint.

## Grammar

- Primary architecture: structural navy, 1.45 units.
- Secondary structure: structural navy at 56%, 0.82 units.
- Micro/reference structure: 0.7–0.72 units, dotted where it represents a guide or horizon.
- Nodes: hollow observation, filled micro observation, and one rust decision signal.
- Fields: 5.5–14% structural navy, used only for analytical regions, overlaps, residuals, or scenario envelopes.
- Decision signal: one small rust event indicating the point at which information becomes decision-relevant.

All marks use a 48×48 coordinate system, round optical joins, geometric precision, and the same signal grammar. Compositions are intentionally non-interchangeable.

## Assignment record

The typed acceptance record lives in `agent-library-data.ts` and explicitly captures each agent's decision problem, analytical mechanism, and visual metaphor. `AgentMarkName` makes missing or invalid assignments a TypeScript error. There is no fallback mark.

## Family QA

`app/agents/_development/EamFamilySheet.tsx` is the temporary review surface. It is deliberately absent from production routing. During a family review, expose it only on a local branch and inspect:

1. 180px close inspection for intersections, tangencies, nodes, radii, and line endings.
2. 58px production tiles with names hidden for silhouette recognition.
3. Grayscale for comparable optical density.
4. Complete agent cards for catalogue rhythm and restraint.

Run a squint test on the card grid and a high-DPI screenshot at 2×. The silhouette, primary structure, and signal must survive at production size; microdetail may recede into atmosphere. The flagship ceiling is set by Vintage, PD Model Monitoring, IFRS 9 / ECL, and Budget & Scenario.

## Interaction and performance

Marks are inline React SVG with CSS only. Hover raises secondary/reference opacity slightly, like an instrument becoming active. There is no theatrical motion, glow, raster asset, canvas, or mark-specific dependency.
