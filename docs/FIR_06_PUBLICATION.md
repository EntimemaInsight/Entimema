## Method and synthetic example

The four-change framework distinguishes absolute, relative, structural and relational movement. The interpretation hierarchy is comparability → scale → relative movement → structure → denominator → cross-statement test → driver hypothesis → evidence → decision, grouped into four existing framework cells.

All example inputs are fictional. Revenue is 50.0 → 59.0; reported EBITDA 5.0 → 5.5; recurring EBITDA 5.0 → 5.0. Gross margin falls 2.03 percentage points; reported EBITDA margin falls 0.68 points. Trade working capital absorbs 4.8, unrestricted cash falls 4.5 → 3.8, and current debt rises 3.0 → 5.1 through a 1.6 maturity transfer and 0.5 new borrowing. Average-stock days measures deteriorate. The current-year cash bridge is −0.6 operating −1.9 investing +3.0 financing = +0.5. Both Balance Sheets and P&L subtotals reconcile.
